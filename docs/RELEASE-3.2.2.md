# 助手 3.2.2 / 游戏 3.2

- 60 名角色新增输出机制、分步循环、实战限制、养成重点、至少两套配队和来源。角色详情中按需展开，推荐队伍可送入队伍 A 比较。
- 九档标准为 00、01、11、21、31、41、51、61、65；00 使用适配泛用 S/A 并说明被动与获取限制。按精炼预留已明确的战斗暴击，克拉蕾允许超百暴。
- “现有抽取建议”位于队伍比较下方。按持有名单安排不重复队伍、养成与补位，再列成型队专武及下一段影画选项。可设置预算、体系、垫抽、大保底。
- 预设、比较和推荐队伍显示限定金 / 全部 S 金；抽取显示新增金、最坏 S 次数 / 抽数 / 菲林。计划队伍已计入目标后的影画或替换音擎。
- v7 存档兼容 v1–v6，新增六档但保留现有方案、引用、账号与登录。仅未编辑旧出厂 00 自动升级音擎，30 个旧方案可完整扩展至 36。
- 原文条件判定补齐同阵营与凯撒其他招架队友。配队资格、持续资源和命中分别说明，未虚构实测 DPS 或当前卡池可用性。

验证：81 项单元测试、冒烟、搜索/多方案/队伍结果/抽取页面 UI、桌面集成；macOS arm64 及 Intel x64 产物启动、存档重启验证。Windows x64 提供同版本构建，未在 Windows 系统实机运行。

安装与清理：替换并重启 `/Applications/绝区零·助手.app`，保留账号、方案与登录；只保留当前 Windows EXE、两种 macOS DMG 及校验清单，删除旧应用、旧安装包、未压缩构建和隔离测试缓存。

推荐不是完整战斗模拟。详见 [机制、金数与抽数预算口径](RECOMMENDATIONS.md)。
