# 自动队伍增益与整体提升

A、B 两队固定同一角色和同一份配置。以目标入场面板为基准，只加入两名队友对目标提供的增益。数值汇总、部件明细及整体提升均排除目标自身技能、影画、音擎被动、四件套战斗效果和自身额外能力；目标的常驻装备属性仍构成固定入场面板。

`提升 = (队伍指标 / 独立配置指标 − 1) × 100%`

`B 相对 A = (B 指标 / A 指标 − 1) × 100%`

## 直接伤害

`指标 = 攻击区 × 增伤区 × 暴击期望 × 防御区 × 抗性区 × 易伤区 × 失衡区`

- 攻击区：入场攻击 × (1 + 战斗攻击加成 / 100) + 固定攻击。
- 增伤区：1 + 适用通用、属性、技能增伤之和 / 100。
- 暴击期望：1 + clamp(暴击率 / 100, 0, 1) × 暴击伤害 / 100；非暴击取 1。
- 有效防御：max(0, 敌防御 × (1 − 减防/无视防御) × (1 − 穿透率) − 穿透值)。
- 防御区：等级系数 / (等级系数 + 有效防御)。按目标等级取值，60 级为 794、1 级为 50。
- 抗性区：1 − 属性抗性 + 减抗/无视抗性。
- 易伤区：1 + 易伤。
- 失衡区：(基础倍率 + 失衡倍率增加) / 100。未失衡时只计明确可在失衡外生效的效果。

统一敌人取 70 级标准防御 953、属性抗性 0%、基础失衡倍率 150%。百分比以百分点保存，18 表示 18%。同区相加、跨区相乘。同一招式倍率在比值中抵消；目标自身的战斗机制不作为队友提升加入。

伤害属性从具体招式读取，混合招式按物理/属性部分比较。队友额外能力按完整三人队伍的属性、阵营或特性要求判断；同名不可叠加的队友音擎被动和同套团队四件效果只计一次。

## 常规属性异常

使用异常精通 / 100，不使用普通暴击。已识别的属性异常独立增伤另作倍率。比较假设同种异常、同一触发者贡献；异常掌控、积蓄效率、持续时间不等同于单次伤害增益。

## 养成与来源

现有使用接口最终面板和完整装备，只读。预设由角色成长、突破阶段、核心常驻属性、音擎基础/高级属性、S 级盘主副属性和两件套生成，可覆盖预设面板及装备数值。突破按等级自动选取，也可在预设中指定。复制账号装备时保留精确主副词条和音擎属性，预设盘统一为 S 级。队友战斗增益按其实际影画、技能、核心、潜能影像、音擎改装和四件套计算。

标准预设分 00（0 影画、1 星泛用音擎）、01（0 影画、1 星专武）、21（2 影画、1 星专武）三档，新预设默认 21。各档按实际属性分别生成 40 次角色优先副词条。潜能影像仅为正式服已开放角色默认 P6，其他角色不可设置。方案独立保存，队伍明确引用方案 ID，详情页切换编辑方案不会改变队伍比较。各档来源及词条口径见 [STANDARD-BUILDS.md](STANDARD-BUILDS.md)。

露西加油：`min(600, 自身入场攻击 × (13 + 0.8 × 特殊技等级)% + 40 + 4 × 特殊技等级)`。账号技能等级已经含影画加级；预设影画三、五各加 2。

苍角：按对应核心的攻击比例和上限，消耗涡流均翻倍。丽娜：按核心比例、固定值、上限与一画倍率处理。动态辅助使用辅助自身属性。

## 完整度边界

资料覆盖 60 名角色、100 个音擎、30 套盘；完整计算范围小于资料库。未映射的队友增益、潜能、低核心动态公式或装备会提示具体原因并暂停完整百分比。目标自身效果因计算范围明确排除，不产生缺失效果警告。

命破贯穿、锋御锐化、特殊异常暴击、紊乱、异放、耀变尚未完整校验。结果不是整队循环 DPS；不模拟覆盖率、能量、积蓄贡献、触发概率、伤害权重或新增攻击段的总循环贡献。

公式参考 [zzzcalc 的计算实现](https://github.com/BanresDev/zzzcalc/blob/main/src/lib/Calculations.ts)；资料来源见 [DATA-SOURCES.md](DATA-SOURCES.md)。
